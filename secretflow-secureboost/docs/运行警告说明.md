# JAX 与 Ray 运行警告说明

## 现象

运行测试或案例时，Python 可能输出以下类型的警告：

```text
RuntimeWarning: os.fork() was called. os.fork() is incompatible with
multithreaded code, and JAX is multithreaded, so this will likely lead to a deadlock.
```

该信息由 Python 在 JAX 已启动多线程后，SecretFlow/Ray 创建子进程时给出。它
是潜在死锁风险提示，不是本项目代码捕获后可以安全忽略的普通日志。

## 当前处置

本项目不在 `pytest.ini` 或代码中屏蔽该警告。当前验证中，完整自动化测试、
玩具案例和 Breast Cancer 案例均能完成，尚未观察到死锁；但这只能说明当前机器
和当前版本组合可运行，不能证明所有机器、所有版本或长时间任务都不存在风险。

## 排查原则

若出现卡住、长时间无 Ray 输出或测试无法退出，应执行以下检查：

1. 新开一个 WSL 终端，确认没有遗留的 Python 或 Ray 进程持续占用资源。
2. 记录 Python、SecretFlow、Ray、JAX、WSL 版本和完整警告文本。
3. 用 `python cases/toy_case.py` 复现最小场景，再尝试 Breast Cancer 案例。
4. 不要先用 `PYTHONWARNINGS=ignore` 或 pytest 过滤规则掩盖警告。
5. 升级或更换 SecretFlow/Ray/JAX 组合时，在新的 Conda 环境中重新执行全部测试和两个案例。

若稳定复现死锁，应将它作为环境兼容性问题处理，而不是通过修改模型参数或隐藏
警告来宣称问题已解决。
