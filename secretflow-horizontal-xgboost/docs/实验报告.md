# SecretFlow 水平联邦 XGBoost 实验报告

## 1. 实验目的

本实验从零实现一个教学型水平联邦直方图 XGBoost 二分类器，并用 SecretFlow
`PYU` 隔离 Alice/Bob 的本地逐样本计算，用 `SecureAggregator` 聚合同形
count/G/H 直方图。实验重点不是复刻生产级 XGBoost 的全部功能，而是验证数学核心、
联邦统计一致性、数据边界、模型复现和工程可测试性。

## 2. 环境

| 组件 | 实测版本/状态 |
|---|---|
| Python | 3.10.20 |
| SecretFlow | 1.13.0b0 |
| XGBoost | 3.2.0 |
| SecureAggregator | 可导入并通过真实聚合测试 |
| `homo_boost.SFXgboost` | 当前版本不可导入 |
| 执行平台 | Windows 11 + WSL Ubuntu，本地 Ray 仿真 |

独立 Conda 环境为 `horizontal-xgb-sf`，没有修改既有垂直 SecureBoost 项目的
`secureboost-sf` 环境。由于 SecretFlow 1.13.0b0 的包元数据固定旧版 XGBoost，
而本任务明确要求官方对照使用 `xgboost==3.2.0`，`pip check` 会报告 XGBoost 版本冲突；
克隆来源本身还是面向本项目的精简环境，未安装 SecretFlow 元数据列出的 TensorFlow、
PyTorch、ONNX 等未使用功能依赖。实际门禁验证了 SecretFlow、SecureAggregator 和
XGBoost 三者均可导入，项目只使用本计划覆盖的接口。该组合不应直接解释为
SecretFlow 全部模块均获得兼容保证，也不能把 `pip check` 视为干净通过。

## 4. 数据

### 4.1 人工案例

人工数据共 16 条，字段为 `sample_id`、`age`、`income`、`purchase_count`、
`credit_score`、`label`。Alice 持有 1--8，Bob 持有 9--16；每方 6 条训练、2 条
测试，四个本地分区均保留两个类别。数据完全由代码确定性构造，不依赖网络下载。

### 4.2 Breast Cancer

使用 `sklearn.datasets.load_breast_cancer()` 的 569 条样本和 30 个数值特征。先以
`test_size=0.2, random_state=42` 做全局分层训练测试划分，再分别对训练、测试索引
按标签分层均分给 Alice/Bob。最终规模为：

| 分区 | 样本数 |
|---|---:|
| Alice train | 227 |
| Bob train | 228 |
| Alice test | 57 |
| Bob test | 57 |
| 总训练 | 455 |
| 总测试 | 114 |

原始 sklearn 行索引生成稳定 `sample_id`；最终评估前按该 ID 排序合并预测和标签。

## 5. 测试结果

最终全量 pytest：`24 passed, 2 warnings in 6.46s`。覆盖稳定 sigmoid、有限差分、叶权重、增益、分桶、
直方图守恒、最优分裂、数据契约、树路由、模型损坏、真实安全聚合、联邦冒烟训练、
集中一致性、重载和隐私审计。

两条 warning 均来自 SecretFlow/Ray 启动阶段：JAX 已启动多线程后调用 `os.fork()`
可能有死锁风险。本次运行未发生死锁，但没有通过 warning 过滤器隐藏它，也不宣称已
从根源解决。

## 6. 人工案例结果

| 模型 | AUC | Accuracy | LogLoss | 训练耗时（秒） |
|---|---:|---:|---:|---:|
| 自写集中式 | 1.000000 | 1.000000 | 0.228587 | 0.002889 |
| 自写水平联邦 | 1.000000 | 1.000000 | 0.228587 | 1.523341 |

联邦训练损失从 `0.529260` 降到 `0.228587`。首棵树根节点选择 `age`，桶索引
`6`、阈值 `33.375`、增益 `3.6`；该结果可由桶级 G/H 前缀和手算复核。联邦与
集中式测试概率最大绝对差为 `2.5083e-07`；模型加载前后差为 0；重复联邦训练模型
JSON 一致。

## 7. Breast Cancer 三模型对照

| 模型 | AUC | Accuracy | LogLoss | 训练耗时（秒） | 模型大小（字节） |
|---|---:|---:|---:|---:|---:|
| 自写集中式直方图 XGBoost | 0.990741 | 0.938596 | 0.221669 | 0.031087 | 24,550 |
| 自写水平联邦直方图 XGBoost | 0.990741 | 0.938596 | 0.221669 | 1.742559 | 24,555 |
| 官方 XGBoost 3.2.0 | 0.989749 | 0.956140 | 0.214462 | 0.229187 | 4,338 |

水平联邦训练损失依次为：

```text
0.486309 -> 0.360504 -> 0.285089 -> 0.233345 -> 0.197295
```

关键一致性指标：

- 联邦与自写集中式预测最大绝对差：`2.8941e-08`，小于 `1e-3`；
- 联邦与官方模型 AUC 差：`0.000992`，小于 `0.10`；
- 联邦概率全部位于 `[0, 1]`；
- 模型加载前后预测最大差：`0.0`；
- 同一配置重复联邦训练模型 JSON 一致；
- 隐私审计通过。

官方模型文件更小，原因包括其紧凑内部 JSON 表示与成熟实现；本项目 JSON 为教学
可读性保存了完整字段名、训练配置、分桶边界、每节点增益和损失历史，不能直接把文件
大小差解释为树统计复杂度差。

## 8. 隐私审计结论

静态检查确认 `client.py` 和 `server.py` 没有 `reveal`。运行时审计确认 Charlie 接收
的消息只有局部特征极值、聚合直方图、聚合叶子统计和聚合损失统计；没有原始表、逐
样本标签、逐样本预测或逐样本 g/h。详细 JSON 位于
`outputs/metrics/breast_cancer_privacy_audit.json`。

这不是形式化安全证明。Charlie 明确可见每方逐特征局部 min/max；本项目没有实现
安全分位数、差分隐私、恶意参与方防护、通信加密部署审计或抗串谋证明。

## 9. 差异与局限

自写集中式与联邦版使用同一数学、分桶、直方图、分裂器和树结构，只在统计来源上
不同。极小预测差来自 `SecureAggregator` 固定点编码/解码，而不是分裂结构差异。
与官方 XGBoost 的预测不要求逐值一致，因为官方实现还包含不同的直方图细节、边界
处理和工程优化。

当前未实现：缺失值默认方向、稀疏矩阵、样本/特征抽样、多分类、回归、早停、增量
训练、分布式持久服务、安全分位数、DP、恶意安全和生产密钥管理。下一步最有价值的
改进是把 min/max 等宽分桶替换为安全的近似全局分位数协议，并用通信量和桶均衡度
做对照，而不是简单增加树深度。
